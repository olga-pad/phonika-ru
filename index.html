Для родителей

Язык обучения

RUENFR
✨ Индивидуальный маршрутPhonika RU показывает только те слова, для которых ребёнок уже освоил необходимые звуки и правила.

Отметьте знакомые звуки. Они сразу будут считаться освоенными и откроют подходящие слова. Ь и Ъ отмечаются как знакомые знаки.

Текущий этап чтения

Выберите размер короткой сессии. По умолчанию — 5. Каждое слово ребёнок читает самостоятельно два раза. Каждое самостоятельное чтение заполняет один кружок. Поэтому для 5 слов на дорожке 10 кружков. Подсказанные и пропущенные карточки остаются в цикле.

Сейчас в работе

Размер сессии выбирается выше. После трёх уверенных отметок звук считается освоенным. Освоенные звуки постепенно заменяются новыми, а трудные остаются в работе.

Сейчас в работе

Размер сессии выбирается выше. В чтении используются только слова выбранного уровня, целиком составленные из уже освоенных звуков. Звуки, которые ещё находятся в работе, слова не открывают. Каждое слово нужно прочитать самостоятельно два раза; подсказанные и пропущенные слова остаются в цикле.
